# Diaries Of Learning

Selamat datang di repositori **Diaries Of Learning**! 🚀

Repositori ini berisi catatan pembelajaran dan proyek praktik dalam pengembangan web, khususnya yang berfokus pada implementasi logika pemrograman dan struktur aplikasi web sederhana menggunakan PHP.

## 📂 Struktur Repositori

Proyek ini disusun dengan struktur dasar MVC (Model-View-Controller) untuk memisahkan logika aplikasi, koneksi database, dan tampilan antarmuka.

* **`/connection`**: Berisi file konfigurasi untuk menghubungkan aplikasi dengan database.
* **`/controller`**: Berisi logika yang menangani permintaan (request) dan menghubungkan model dengan view.
* **`/views`**: Berisi file antarmuka pengguna (UI) yang akan ditampilkan di browser.
* **`tes.php`**: File pengujian untuk memastikan fungsi atau logika tertentu berjalan dengan baik.

## 🛠️ Teknologi yang Digunakan

* **Bahasa Pemrograman**: PHP (Native)
* **Arsitektur**: MVC Sederhana
* **Database**: MySQL (Diasumsikan, berdasarkan folder connection)

## 🚀 Cara Menjalankan

Untuk menjalankan proyek ini di mesin lokal Anda, pastikan Anda telah menginstal Web Server (seperti XAMPP, WAMP, atau Laragon).

1.  **Clone repositori ini:**
    ```bash
    git clone [https://github.com/ELGHIFARY111/Diaries_Of_Learning.git](https://github.com/ELGHIFARY111/Diaries_Of_Learning.git)
    ```
2.  **Pindahkan folder:**
    Pindahkan folder hasil clone ke dalam direktori root server lokal Anda (misalnya: `htdocs` untuk XAMPP atau `www` untuk Laragon).
3.  **Konfigurasi Database:**
    Cek folder `connection` dan sesuaikan kredensial database (username, password, nama database) dengan pengaturan lokal Anda jika diperlukan.
4.  **Jalankan di Browser:**
    Buka browser dan akses:
    `http://localhost/Diaries_Of_Learning`
